# dsh-tcm-xueli · 中医预设「中医 · 经方（学习版）」

给 DeepSeek Harness（DSH）用的中医插件。装上以后，DSH 里多出一个「中医 · 经方（学习版）」预设，能陪你按经方思路学中医。

问诊先像坐诊一样问清寒热、出汗、二便、睡眠、舌象，六部脉一部一问；再按随包九部经典讲清这个证属哪一经、病机在哪、该用哪一类方、该取哪几个穴，并教你服后怎么核对方向对不对。

**只讲思路，不给克数，不出处方笺，针灸只给穴位、不给针法**，也不往资料库里放任何规程文件。

- 插件名（＝npm 包名＝行 id）：`dsh-tcm-xueli`
- 预设名：中医 · 经方（学习版）（预设 id：`dsh-tcm-xueli`）
- 设置页入口：设置 → 中医 · 经方
- 资料库：**不预设目录**，装好后自己在设置页填一个（填之前不建索引、不归档、不补随包经典）
- 运行要求：DSH ≥ 0.2.2-rc.1，不用另装 Node 或 Python

## 装了能干什么

| 功能 | 说明 |
|---|---|
| 问诊 | 先问性别、年龄、体重，再按你说的症状追问寒热、出汗、二便、睡眠、饮食、舌象；六部脉逐部单独问，每部先给脉象选项，不会把脉就改选该部对应的症状，六部都要问到 |
| 辨证 | 六经或脏腑定位、主证兼证、病机，引用《内经》《难经》《伤寒杂病论》原文并注明条号或篇名 |
| 讲方 | 给代表方名、每味药在方里的分工、什么证加什么减什么（只说药性与方向，不给克数） |
| 讲穴 | 推荐主穴、配穴、左右，说明取穴依据（不写深浅、手法、补泻、留针、疗程） |
| 治则与调护 | 治法次第、饮食作息、煎服的一般原则，以及什么反应说明方向对了、什么情况必须去看医师 |
| 资料库索引 | 启动时把随包十册经典（即作答依据的九部书）补到 `text/`，按目录自动生成 `索引.md`，根目录新书按内容归到经典、经典注解、名著、医案、方药五个文件夹 |
| 会话归档 | 本预设的对话自动存一份 Markdown 到资料库的 `医案/`，一个会话一份 |
| 改路径即时生效 | 在设置页换资料库目录，下一句话就按新目录找书，不用重启 |

## 为什么可以放心用

- 口径写死在提示词最前面（只有一份，`lib/gear.js` 里维护），每次请求都随系统提示词发下去；讲话里一旦冒出克数（含 `g`），插件只把「克」前面的数字遮成 `✳`，药名和句子骨架都留着；两、钱、枚、毫升这类经典计量和原文引文一律不遮。
- 全程标着「仅供学习研究，不构成诊疗建议」，回答末尾固定带一句声明。

## 它不给什么

- 不给任何剂量：克数（含 `g`）不给，也不给原方折克、推荐量、临床区间、药典上限；引原文、转述别人方子上的经典计量照原话引。
- 不出处方笺、剂量表，不写「照此抓药」「按此服用」。
- 不给针法：深浅、角度、手法、补泻、留针时间、疗程频次、灸几壮都不写。
- 不替你决定要不要吃药、要不要扎针；有需要请找执业中医师面诊。

## 回答长什么样

每次回答按固定次序来，前四样缺一样就算不合格：

**一、先给一行结论**

> **结论**：您这是肝气憋着、脾胃跟着虚弱了，眼下先顺气疏肝，别熬夜，生冷先停一停。

**二、再写「## 手上的线索」**

三行固定句式，写明这条线索够不够定病、定证、定脉：

```
够定的是：……
不够定的是：……
所以要问的是：……
```

线索不够，它会直接弹按钮问你（每题一组选项，含「略过」）；问完这一轮就停下等答案，不会边问边下结论。

**三、「## 六经与时令」**

先说这个证归哪一经（不典型就明写「六经归属不典型，以脏腑辨证为主」），再讲脏腑经络定位，最后讲当下时令——现在什么季节、处在哪两个节气之间、今年什么干支、走的是五运六气的第几气。

**四、再按七段讲**

1. **辨证定位**：六经归属与脏腑经络定位（两样都要说），主证兼证，标病本病、轻重缓急。
2. **治则治法**：先治什么后治什么，分几步走。
3. **代表方与加减方向**：方名、组成、加减都能讲，唯独不给克数；库里没有的方照写方名，并在后面标「（本库未收此方原文）」。
4. **推荐穴位**：取哪几个穴、左右哪侧，依据哪条原文；方核不到原文时，穴位仍要给。
5. **配伍禁忌提醒**：十八反、十九畏、妊娠禁忌、毒性药同用、中西药同服风险，只提方名也会点明。
6. **药典用量警示**：这味药在药典里处于什么水平、毒性多大、该怎么炮制煎法，不给数字。
7. **调护与就医提示**：作息饮食寒温忌口情绪，什么情况必须去医院（单独一行粗体「**⚠️ 立刻上医院**」）。

**方证依据只有两套**：五运六气（干支、中运太少、司天在泉、当前这一气的主气客气都由插件按日期算好写进提示词，模型照抄，再引《素问》运气七篇原文），加上仲景的辨证体系（以八纲为基石、以六经为框架，讲传变与合病并病，落到「知犯何逆，随证治之」）。整体观念、审证求因、四诊合参、辨病与辨证结合、阴性症状与鉴别诊断这五种方法贯穿全篇。

**两条硬红线**：

- **剂量**：不写克数（含 `g`），也不写每日几服、连服几剂。回答里出现克数的，只把「克」前面的数字遮成 `✳`，药名和句子照常显示（生姜 25g → 生姜 ✳）；两、钱、枚、毫升与原文引文不动，列表项前缀不碰，成段转述整张方（同一段 4 味以上）整段放行。
- **引原文**：打引号引原文、报条文号，都必须先核到资料库原文；核不到就不许打引号、不许报号，也不许把出处硬挂到某本书上。

古文一律先翻成白话，原文放括号里作点缀并注明书名篇名。危险动作句首带 🚨 或 ⚠️，写成能照着做的动作。食养、食疗、药膳、代茶饮可以讲方向，但不给具体分量；中成药和保健品不推荐，会让你找医师面诊。

末尾固定两行：

```
【中医 · 经方（学习版）】本节仅供学习研究，不构成诊疗建议；如需用药或施针请由执业中医师面诊。
⚠️ AI 有幻觉：以上内容由人工智能生成，可能编造原文、记错条文或张冠李戴，请自行核对原书后再用。
```

## 技术上怎么实现的

1. **注册预设**：预设、问诊、七段格式都写在 `cordis.patch.yml` 里，随插件一起装进 DSH 的预设列表。
2. **口径锁**：学理模式总纲只在 `lib/gear.js` 里维护一份，预设提示词第一行用 `{{tcm_gear_guard}}` 展开，每次请求随系统提示词发一遍，不再手抄第二份。
3. **出口校验**：模型回答里一旦出现克数（含 `g`），只把「克」前面的数字换成 `✳`，药名和句子骨架原样留着；两、钱、枚、毫升与原文引文不动；列表项前缀不打码，同一段转述整张方（4 味以上）整段放行；其余照常输出，末尾记一条日志。
4. **资料库维护**：启动时补随包十册经典（即九部依据书）到 `text/`，按目录生成 `索引.md`，按内容把根目录新书归到五个分类文件夹，改路径后自动切换。
5. **会话归档**：本预设的会话自动存一份 Markdown 到 `<资料库>/医案/`。
6. **只补书不写规程**：不往资料库的 `skills/`、`references/` 放检索或出方规程。

## 想让它引更多书，自己往资料库放

插件随包带十册经典，合起来正是作答所依据的九部书（《黄帝内经》素问与灵枢算一部）：分析理法阴阳用《黄帝内经》《难经》，提取方证对应用《伤寒论》《金匮要略》，分析脉象用《脉经》《濒湖脉学》，针灸经络用《针灸甲乙经》，《神农本草经》只查药性，《桂林古本伤寒杂病论》只作条文校勘。教科书、网文、课堂笔记一律不作依据。

想让它认得更多书，**自己把古籍放进资料库就行，不用改插件**：放进去的书算你的补充，引用时照样以原文为准；没放进资料库的书，它只会说「本库未收」。

下面以《本草新编》（陈士铎）为例——这本插件不随包带，有版权，不好替大家分发：

**第一步 准备文件**：找一份纯文本版（`.txt`）或 Markdown 版（`.md`）。扫描版 PDF 虽然能放进去，但插件只能读文字层，读不出内容。

**第二步 放对地方**：**直接复制进资料库根目录就行**（就是你填的那个目录），插件会按书名和正文自己归到对应文件夹，不用你管。文件名里带「本草、良方、方书、方剂、本草经」这些字眼的，会归到 `方药`。

**第三步 重启 DSH，再新建一个会话**。插件会在启动时重建 `索引.md`，新书就出现在对应分类里。之后问它药性，它会按规矩先查库、引原文。

**插件会自动把它挪到哪儿**（不用手动分文件夹）：

| 书名或正文里有 | 归到 |
|---|---|
| 本草、良方、方书、方剂、方解、汤头、药性、气味、炮制 | `方药` |
| 医案、病案、治验、验案、临证录 | `医案` |
| 讲义、讲稿、白话、浅释、校注，或作者是倪海厦、胡希恕、刘渡舟 | `经典注解` |
| 全书、秘录、医论、卷一、卷二，或作者是世补斋、徐灵胎、陈士铎 | `名著` |
| 素问、灵枢、伤寒论、金匮要略、难经、脉经、神农本草经 | `经典` |

**拿不准的会留在根目录不动**，等你自己挪。想指定分类，直接把它放进对应文件夹最省事。

**两个提醒**：

- 千万别放进 `skills/`、`references/` 这两个文件夹，那是规程专用，书放进去会被当成规程。
- 文件不要带 `.bak` 后缀，备份文件不进索引，也不会被自动归类。

**放没放成功怎么确认**：打开资料库根目录的 `索引.md`，在里面搜书名。搜得到就是进去了；搜不到就重启一次 DSH 再看。

## 安装（给没用过的人看）

> **先说一句**：npm 上同名那个包（`dsh-tcm-xueli`）是作者早期留下的 1.3.0 旧版，原账号已注销、包被 npm 官方接管，改不动也发不了新版。所以本插件**不从 npm 装**，请用下面两种方式之一：解压文件夹装，或命令行装。本仓库的版本号与说明才是最新的。

**先决条件**：本机装好 DSH 桌面版。不用另装 Node、Python 或任何东西，DSH 自带。

### 方法一：解压压缩包，在 DSH 里填路径（推荐，不用命令行）

**第一步：下载**

打开 <https://github.com/yeweiliang7063/dsh-tcm/releases/latest>，点 **Source code (zip)** 下载压缩包。或者仓库首页绿色 **Code** 按钮 → **Download ZIP**。

**第二步：解压**

解压到一个**短、纯英文、没有空格**的路径下，例如 `D:\dsh-tcm-xueli`。

- Windows：不要放在「下载」「桌面」这类中文目录里套很多层
- macOS：例如 `/Users/你的用户名/dsh-tcm-xueli`
- Linux：例如 `~/dsh-tcm-xueli`

解压完打开文件夹看一眼，里面应该直接能看到 `package.json`、`lib`、`install.mjs` 这些。如果还套着一层同名文件夹，进到里面那层再用。

**第三步：在 DSH 里添加**

1. 打开 DSH，左侧点「**插件**」
2. 找「**添加插件**」按钮
3. 弹出的框里填**刚才解压出来的那个文件夹的完整路径**（Windows 比如 `D:\dsh-tcm-xueli`）
4. 点「**安装**」

看到「已安装」就成了。

**第四步：重启 DSH**

**完全退出 DSH（从右下角托盘退出，只关窗口不算），再重新打开。**

**第五步：用起来**

在 DSH 里**新建一个会话**，在预设列表里选「中医 · 经方（学习版）」。老会话不会变成中医预设，必须新建。

### 方法二：命令行装（填路径装不上时用）

同样先下载解压，然后打开命令行：

| 系统 | 怎么打开命令行 |
|---|---|
| Windows | 打开解压出来的文件夹 → 点上面的地址栏把路径删掉 → 输入 `powershell` 回车 |
| macOS | 访达里在文件夹上右键 →「服务」→「新建位于文件夹位置的终端窗口」 |
| Linux | 文件管理器里在文件夹空白处右键 →「在终端中打开」 |

在弹出的窗口里敲这一句，回车：

```
node install.mjs
```

只想看它会做什么、不改任何东西，就敲 `node install.mjs --dry-run`。

等窗口里出现「安装完成」，再**完全退出 DSH 重新打开**。

### 装完要知道的三件事

| 要说的 | 说明 |
|---|---|
| 资料库 | **没有默认目录**，路径由你在「设置 → 中医 · 经方」里自己填。没填之前插件什么都不做：不建索引、不归档、不补随包经典；此时回答只会给治法方向，不引书、不报方名 |
| 怎么卸 | 在 DSH 里把 `dsh-tcm-xueli` 这个插件关掉或卸载即可，不影响 DSH 其它功能。**源码文件夹不会被删，随时能再装回来** |
| npm 上那个同名包 | npm 上的 `dsh-tcm-xueli` 是作者早期版本 1.3.0，账号已注销、被 npm 官方接管，无法更新，**不要从 npm 装**；本插件按上面的解压或命令行方式装 |

### 安装脚本做了什么（给想确认的人）

建链接 → 写入 profile 的 `dsh.profile.bundles` 与 `dependencies`（改前自动备份成 `package.json.bak-tcm-install-<时间>`）→ 自检 → 提示资料库目录。只做登记与链接，不改 profile 里其它任何一行。

**会不会要管理员权限**：Windows 上用的是 junction（目录联接），不需要管理员；macOS、Linux 上用的是目录软链接，也不需要用 `sudo`。如果 macOS 上提示「操作不被允许」，多半是解压后的文件夹放在「下载」里被系统保护了，换个地方解压重试。
