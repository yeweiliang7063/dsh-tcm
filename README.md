# dsh-tcm · 中医预设「岐黄经方（学习版）」

给 DeepSeek Harness（DSH）用的中医插件，**仅供学习研究**：回答只给**辨证思路**，不给具体剂量，不出处方笺，针灸只给推荐穴位、不给用法。

- 插件名：`dsh-tcm`
- 预设名：中医 · 岐黄经方（学习版）（预设 id：`dsh-tcm`）
- 设置页入口：设置 → 中医资料库 · 学理模式
- 资料库：默认 `D:\中医知识库`（macOS / Linux 用 `~/中医知识库`），可在设置页改

## 说清楚：学理模式到底给什么

| 给 | 不给 |
|---|---|
| 六经或脏腑定位、主证与兼证、舌脉与病机 | 任何克数、钱数、两数、枚数、毫升数 |
| 治则治法、分步次第 | 原方剂量、折克、推荐量、区间量、药典上限 |
| 代表方名、各方下药味的加减方向 | 处方笺、剂量表、「照此抓药」「按此服用」 |
| 推荐穴位（主穴、配穴、左右）与取穴依据 | 针法、深浅、角度、补泻、留针、疗程频次、灸几壮 |
| 饮食作息与调护原则、什么情况该去看医师 | 把内容当作可以照着抓药、照着下针的方案 |

回答固定五段：一、辨证定位；二、治则治法；三、代表方名与加减方向；四、推荐穴位；五、调护与就医提示。末尾固定一行声明：
`【学理模式】本节仅供学习研究，不构成诊疗建议；如需用药或施针请由执业中医师面诊。`

## 它做了什么

1. **注册预设**：先问诊（性别、年龄、体重，再按描述追问寒热、出汗、二便、睡眠、饮食、舌象、六部脉），答齐后按五段作答。问诊只问脉证。
2. **口径锁**：学理模式总纲挂在预设提示词最前面，并作为常驻提示词变量在每次请求里再压一遍，任何「给出剂量、出处方笺」的写法都以它为准。
3. **出口校验**：模型回答里一旦出现剂量数值（克、钱、两、枚、毫升、升、合、钱匕），当场停止这次回答，换成一句提醒交给用户——不靠模型自觉。
4. **资料库维护**：启动时补随包十部经典到 `text/`，按目录生成 `索引.md`，按内容把根目录新书归到五个分类文件夹，改路径后自动切换。
5. **会话归档**：本预设的会话自动存一份 Markdown 到 `<资料库>/医案/`。
6. **不往资料库写规程**：只补书与索引，不往 `skills/`、`references/` 放检索或出方规程。

## 安装

```powershell
# 插件目录下运行
node install.mjs            # 只看会做什么可加 --dry-run
```

安装脚本会：建链接 → 写入 profile 的 `dsh.profile.bundles` 与 `dependencies`（改前自动备份成 `package.json.bak-tcm-install-<时间>`）→ 自检 → 提示资料库目录。装完重启 DSH，新建会话时在预设列表里选「中医 · 岐黄经方（学习版）」。

## 自检与测试

```bash
node verify-preset.mjs      # 只读检查：插件本体、预设声明、口径锁、资料库、副本一致、真实加载
npm test                    # 单元测试：路径、索引、归档、剂量校验、配置项
node test/simulate.mjs      # 加载模拟：提示词变量、事件拦截、目录监视、索引生成
```

## 目录结构

```
dsh-tcm/
├─ package.json
├─ cordis.patch.yml        # 插件行、预设定义（含口径锁）
├─ lib/
│  ├─ index.js             # 宿主半：变量、出口校验、索引、目录监视、归档
│  ├─ gear.js              # 常量与固定文案（口径锁、拦截提醒）
│  ├─ dosage-guard.js      # 剂量数值识别与打码
│  ├─ preset.js            # 预设文件缺失时的兜底骨架
│  ├─ client.js            # 浏览器半：设置页「中医资料库 · 学理模式」
│  ├─ platform.js          # 跨平台路径工具
│  ├─ kb-index.js          # 索引生成器与分类文件夹
│  ├─ corpus.js            # 只补随包经典
│  ├─ records.js           # 会话归档
│  ├─ book-text.js / book-classify.js / auto-file.js
│  └─ build-index.mjs
├─ corpus/                 # 十部经典纯文本
├─ assets/references/bianzheng-lu.md  # 学理模式辨证思路规程（供查阅，不随包进资料库）
├─ install.mjs / verify-preset.mjs
└─ test/
```

## 说明

- 第三方插件，非 DSH 官方出品。
- 任何异常都在插件边界内捕获：读不到配置退回默认目录，出口校验注册失败只靠提示词，绝不影响 DSH 主体启动。
- 随包十部经典（素问、灵枢、伤寒论、金匮要略、桂林古本、难经、针灸甲乙经、脉经、濒湖脉学、神农本草经）为公有领域古籍的纯文本。
- 本插件不构成任何医疗建议。用药、施针请由执业中医师面诊。
