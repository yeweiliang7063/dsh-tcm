# dsh-tcm · 中医预设「岐黄经方（学习版）」

给 DeepSeek Harness（DSH）用的中医插件。装上以后，DSH 里多出一个「中医 · 岐黄经方（学习版）」预设，能陪你按经方思路学中医：先像坐诊一样问清寒热、出汗、二便、睡眠、舌象、六部脉，再按《黄帝内经》《难经》《伤寒杂病论》讲清这个证属哪一经、病机在哪、该用哪一类方、该取哪几个穴，并教你服后怎么核对方向对不对。**只讲思路，不给克数，不出处方笺，针灸只给穴位、不给针法**，也不往资料库里放任何规程文件。

- 插件名：`dsh-tcm`
- 预设名：中医 · 岐黄经方（学习版）（预设 id：`dsh-tcm`）
- 设置页入口：设置 → 中医资料库 · 学理模式
- 资料库：默认 `D:\中医知识库`（macOS / Linux 用 `~/中医知识库`），可在设置页改
- 运行要求：DSH ≥ 0.2.2-rc.1，不用另装 Node 或 Python

## 装了能干什么

| 功能 | 说明 |
|---|---|
| 问诊 | 先问性别、年龄、体重，再按你说的症状追问寒热、出汗、二便、睡眠、饮食、舌象，六部脉分开问；不会把脉可以选括号里的症状代答 |
| 辨证 | 六经或脏腑定位、主证兼证、病机，引用《内经》《难经》《伤寒杂病论》原文并注明条号或篇名 |
| 讲方 | 给代表方名、每味药在方里的分工、什么证加什么减什么（只说药性与方向，不给克数） |
| 讲穴 | 推荐主穴、配穴、左右，说明取穴依据（不写深浅、手法、补泻、留针、疗程） |
| 治则与调护 | 治法次第、饮食作息、煎服的一般原则，以及什么反应说明方向对了、什么情况必须去看医师 |
| 资料库索引 | 启动时把随包十部经典补到 `text/`，按目录自动生成 `索引.md`，根目录新书按内容归到经典、经典注解、名著、医案、方药五个文件夹 |
| 会话归档 | 本预设的对话自动存一份 Markdown 到资料库的 `医案/`，一个会话一份 |
| 改路径即时生效 | 在设置页换资料库目录，下一句话就按新目录找书，不用重启 |

## 为什么可以放心用

- 口径写死在提示词最前面，每次请求再压一遍；讲话里一旦冒出克数、钱数、两数、枚数、毫升数，插件当场截断这次回答并提醒你——不靠模型自觉。
- 全程标着「仅供学习研究，不构成诊疗建议」，回答末尾固定带一句声明。

## 它不给什么

- 不给任何剂量：克、钱、两、枚、毫升都不给，也不给原方折克、推荐量、临床区间、药典上限。
- 不出处方笺、剂量表，不写「照此抓药」「按此服用」。
- 不给针法：深浅、角度、手法、补泻、留针时间、疗程频次、灸几壮都不写。
- 不替你决定要不要吃药、要不要扎针；有需要请找执业中医师面诊。

## 回答长什么样

每次回答先给一行人话，再按七段讲：

> 👉 **【大白话结论】**：您是心里憋着火、脾胃又被拖垮了，眼下先顺着脾气来，别熬夜别生冷；出现心慌胸痛、喘不上气，立刻去医院。

1. **辨证定位**：六经或脏腑归哪里，主证兼证，标病本病、轻重缓急。
2. **治则治法**：先治什么后治什么，分几步走。
3. **代表方与加减方向**：用哪一类方，每味药管什么，什么证加哪类药、什么证减哪类药；实邪要攻、底子又虚时，先给攻补兼施的路数。
4. **推荐穴位**：取哪几个穴、左右哪侧，依据哪条原文。
5. **配伍禁忌提醒**：十八反、十九畏、妊娠禁忌、毒性药同用、中西药同服风险，只提方名也会点明。
6. **药典用量警示**：这味药在药典里的用量处于什么水平、毒性多大、该怎么炮制煎法，不给数字。
7. **调护与就医提示**：吃什么不吃什么、作息怎么调，什么情况必须去看医师。

古文一律先翻成白话，原文只放括号里作点缀。危险动作句首带 🚨 或 ⚠️，写成能照着做的动作。

末尾固定一句：`【学理模式】本节仅供学习研究，不构成诊疗建议；如需用药或施针请由执业中医师面诊。`

## 技术上怎么实现的

1. **注册预设**：预设、问诊、七段格式都写在 `cordis.patch.yml` 里，随插件一起装进 DSH 的预设列表。
2. **口径锁**：学理模式总纲挂在预设提示词最前面，并作为常驻提示词变量（`tcm_gear_guard`）在每次请求里再压一遍。
3. **出口校验**：模型回答里一旦出现剂量数值（克、钱、两、枚、毫升、升、合、钱匕），当场停止这次回答，换成一句提醒交给用户。
4. **资料库维护**：启动时补随包十部经典到 `text/`，按目录生成 `索引.md`，按内容把根目录新书归到五个分类文件夹，改路径后自动切换。
5. **会话归档**：本预设的会话自动存一份 Markdown 到 `<资料库>/医案/`。
6. **只补书不写规程**：不往资料库的 `skills/`、`references/` 放检索或出方规程。

## 安装

```powershell
# 插件目录下运行
node install.mjs            # 只看会做什么可加 --dry-run
```

安装脚本会：建链接 → 写入 profile 的 `dsh.profile.bundles` 与 `dependencies`（改前自动备份成 `package.json.bak-tcm-install-<时间>`）→ 自检 → 提示资料库目录。装完重启 DSH，新建会话时在预设列表里选「中医 · 岐黄经方（学习版）」。

## 自检与测试

```bash
node verify-preset.mjs      # 只读检查：插件本体、预设声明、口径锁、资料库、副本一致、真实加载
npm test                    # 单元测试：路径、索引、归档、剂量校验、配置项
node test/simulate.mjs      # 加载模拟：提示词变量、事件拦截、目录监视、索引生成
```

## 说明

- 第三方插件，非 DSH 官方出品。
- 任何异常都在插件边界内捕获：读不到配置退回默认目录，出口校验注册失败只靠提示词，绝不影响 DSH 主体启动。
