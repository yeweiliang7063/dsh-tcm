## 说明

- 这些著作均属公版古籍，原文无著作权，仅供学习、研究与教学参考，不能替代医师诊断与处方。
- 九个来自 TCM-Ancient-Books 的文件原为 GB18030 编码，已转为 UTF-8，并去掉源文件的书目信息块、`<目录>`、`<篇名>`、`属性：`、`\x` 等结构标记，正文文字未作改动。
- `02-黄帝内经灵枢.txt` 取自中文维基文库，按第一卷至第十二卷顺序拼接，保留篇题（共 81 篇），文字沿用该站繁体原文，未转简体。

- `10-神农本草经.txt` 为孙星衍（渊如）辑本，保留邵序、张序、孙序与上经、中经、下经三卷，一物一条，正文首字「味」照录；底本卷三之末的《诸药制使》（七情配伍与畏恶，按玉、石、草、木、兽、虫鱼、果、菜、米各部排列）已作为「附：诸药制使」收在文末，照底本旧分组逐味一行，原文一字不改；底本另附的《吴氏本草》十二条不收。
- 少数生僻字在所据源文件中即已缺失（如「㕮咀」「瘛疭」处留下空格），属来源限制，未作推测性补字。
